# Blue Runner

2D-платформер, дисципліна «Дизайн та розробка комп'ютерних ігор (Unity)», КНЕУ.

Орлов А. І., ІН-401.

Unity 6.6 (6000.6.0f1), шаблон Universal 2D.

## Лабораторні

- `lab-02` — каркас проєкту, тайлсет, перша збірка
- `lab-03` — контролер, спрайт героя, juice та звук
- `lab-04` — навчальний рівень: Tilemap, камера, глибина
- `lab-05` — вороги та бойова система

## Керування

- A / D — рух
- Space — стрибок
- E — взаємодія (важіль)

Графіка: Kenney 1-Bit Platformer Pack (CC0), перефарбована в палітру Sweetie 16.
